# MLSD · Интерактивная карта POI Москвы

Статическая веб-карта (HTML/CSS/JS + Leaflet), готовая к публикации на GitHub Pages.

## Возможности

- 6 режимов отображения: точки · кластеры · круговые диаграммы (состав кластера
  по категориям) · гексагоны (5–50 га) · картодиаграмма по округам · по районам
- Знаменатель картосхемы: абсолют · объектов на 1 км² · на 100 тыс. жителей
  (площадь и население берутся из атрибутов слоёв границ, поля настраиваются
  в `CONFIG.adminFields`)
- Вложенные фильтры: слайд → категория. Категория — рубрика 2GIS из колонки «Ссылка запроса»
  (или из имени файла), слайды задаются в `CONFIG.slides` (rubricId → слайд).
  Дубли внутри категории убираются по `2GIS URL`; в карточке «Данные» — уникальные точки
  против «Найдено N» из 2GIS
- Точки за границей Москвы (`data/moscow.geojson`) отбрасываются: выдача 2GIS по Москве
  захватывает область. Выключается `CONFIG.clipToMoscow = false`
- Тултип при наведении на точку (без контактов и времени работы)
- Попапы-карточки для округов и районов: количество объектов + топ категорий
- Рисование зоны (полигон / прямоугольник) и выгрузка точек в CSV / XLSX / GeoJSON
- Подложки: CARTO Positron, тёмная (CARTO Dark Matter), OSM
  (тайлы Яндекс-карт напрямую недоступны — раздаются только через их API с ключом)
- Слои административных границ: округа и районы Москвы (из ваших GPKG, WGS84, упрощены)
- Транспортные кольца: Садовое, ТТК, МКАД (OSM, обе проезжие части, упрощены до ~10 м)
- Дэшборд под картой (Z-паттерн): KPI агрегата, структура по слайдам с разбивкой
  выбранного слайда на категории (учитывает фильтры карты), агрегация по любой
  полигональной структуре — все точки, Москва (объединение округов,
  `data/moscow.geojson`), округ, район, загруженная зона доступности
- Зоны доступности (изохроны): загрузка GeoJSON / JSON / GPKG кнопкой или из папки
  `data/zones/` (после добавления файлов запустите `update_manifest.bat`).
  Вкл/выкл, выбор цвета, линия/пунктир. GPKG читается прямо в браузере
  (sql.js), поддерживаются проекции EPSG:4326, 3857 и UTM 326xx/327xx

## Структура

```
MLSD_web_map/
├── index.html            — страница
├── css/style.css         — стили (Metro / карточный дизайн)
├── js/app.js             — логика (все настройки в CONFIG вверху файла)
├── data/
│   ├── okruga.geojson    — округа Москвы
│   └── rayony.geojson    — районы Москвы
├── MLSD_moscow_data/     — папка с CSV-данными (2GIS-формат)
│   └── manifest.json     — список загружаемых CSV
├── update_manifest.py    — синхронизация папки данных (+ .bat)
└── start_server.bat      — локальный предпросмотр
```

## Синхронизация данных

1. Положите новые CSV в `MLSD_moscow_data/`
2. Запустите `update_manifest.bat` (или `python update_manifest.py`)
3. Обновите страницу — карта подхватит все файлы из manifest.json

Требования к CSV: колонки `Широта`, `Долгота`, `Ссылка запроса` (или имя файла вида `moscow_<рубрика>_<rubricId>.csv`)
(названия полей меняются в объекте `CONFIG` в начале `js/app.js`).

## Локальный запуск

Открытие `index.html` двойным кликом не сработает (браузер блокирует fetch на file://).
Запустите `start_server.bat` — откроется http://localhost:8000.
Как запасной вариант карта умеет загружать CSV вручную через кнопку в окне ошибки.

## Публикация на GitHub Pages

1. Создайте репозиторий и залейте содержимое папки целиком:
   ```
   git init
   git add .
   git commit -m "MLSD web map"
   git branch -M main
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```
2. В репозитории: Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)`
3. Карта будет доступна по адресу `https://<user>.github.io/<repo>/`

## Настройка под новые поля

Все названия полей — в объекте `CONFIG` в начале `js/app.js`:

- `slides` — распределение рубрик (rubricId) по слайдам; `fieldQuery`, `fieldDedup` — поля категории и дедупликации
- `tooltipFields` — список полей тултипа
- `fieldLat`, `fieldLon`, `fieldName` — координаты и название точки
